How It Works
1

Upload Audio

Your file is read in the browser, then securely sent to Cloudinary via a serverless function.

2

Cloudinary Stores the Audio

Audio lives on Cloudinary's CDN — fast, reliable, permanent. No expiry.

3

Player Page Deployed

A lightweight player HTML page is instantly generated and served from Vercel using the Cloudinary audio URL.

4

Embed in Canva

Paste the URL in Canva's Embed app. Only the play button shows — fully transparent background.
